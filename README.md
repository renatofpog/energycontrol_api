# EnergyControl API

> Back-end RESTful em Java e Spring Boot desenvolvido para a aplicação **EnergyControl** (Projeto UPX-2), focado na gestão e monitorização de consumo energético de equipamentos elétricos.

---

## Sobre o Projeto

O **EnergyControl** é uma plataforma que auxilia pequenos empreendedores no gerenciamento de gastos energéticos durante o mês.

Esta API fornece todo o ecossistema de back-end para cadastro de utilizadores, autenticação segura com **JWT**, e gestão completa (CRUD) dos equipamentos cadastrados com isolamento total dos dados por utilizador.

---

## 🚀 Tecnologias Utilizadas

* **Linguagem:** Java 17+
* **Framework:** Spring Boot 3
* **Base de Dados:** MySQL
* **Segurança:** Spring Security, BCrypt, JWT (JSON Web Token)
* **Outras bibliotecas:** `dotenv-java` (gestão de variáveis de ambiente)

---

## 🔐 Segurança e Autenticação

A API utiliza autenticação baseada em tokens **JWT (JSON Web Token)**
